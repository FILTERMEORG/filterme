# VS Code에서 UI 직접 보면서 개발하기

매번 `chrome://extensions`에서 새로고침하고 유튜브 라이브 방송을 열어야 하는 게 번거로울 때,
`dev/` 폴더의 미리보기 페이지로 브라우저 UI만 빠르게 확인할 수 있습니다.

**중요**: `content.js`, `popup.html`, `popup.js`를 복사하거나 수정한 게 아니라, 미리보기 페이지가
그 파일들을 **있는 그대로** 불러와서 그립니다. 즉 여기서 보는 화면이 곧 실제 확장 프로그램 코드의
결과물입니다.

## 준비물

VS Code 확장 마켓에서 **Live Server** (Ritwick Dey) 설치. (다른 정적 서버여도 상관없습니다 —
`npx serve`, `python3 -m http.server` 등. 단, 반드시 `http://localhost` 로 열어야 합니다.
`file://`로 직접 열면 브라우저에 따라 팝업 미리보기 쪽 동기화가 깨질 수 있습니다.)

## 사용법

1. VS Code에서 이 프로젝트 폴더를 엽니다
2. `dev/index.html` 파일을 우클릭 → **Open with Live Server**
3. 브라우저에 두 개의 박스가 뜹니다
   - 왼쪽: 유튜브 라이브 채팅을 최소한으로 흉내 낸 목업 (`content.js`가 그 안에서 그대로 실행됨)
   - 오른쪽: 브라우저 툴바 아이콘을 눌렀을 때 뜨는 팝업(`popup.html`)을 그대로 렌더링한 것
4. 상단 버튼(💬 일반 / 🤬 욕설 / 🏛 정치 / 🔁 도배)을 눌러 가짜 채팅 메시지를 채팅 목업에 추가해서
   실제로 블러/차단되는지 확인할 수 있습니다
5. `content.js`나 `popup.js`를 수정하고 저장하면 Live Server가 자동으로 새로고침해줍니다

## 두 화면이 실시간으로 동기화되는 이유

`dev/chrome-mock.js`가 실제 `chrome.storage.local` API를 흉내 낸 가짜 구현체입니다.
`localStorage`를 저장소로 쓰고, 브라우저의 네이티브 `storage` 이벤트를 이용해서 왼쪽(채팅 iframe)과
오른쪽(팝업) 사이의 설정 변경을 서로에게 알려줍니다 — 실제 `chrome.storage.onChanged`가
여러 컨텍스트에 전파되는 것과 같은 경험을 흉내 낸 것입니다.

`dev/popup-embed.html`은 v0.3.0 리팩터링(설정 화면을 `<iframe>`으로 `popup.html`을 재사용하는
구조)을 이 미리보기 환경에서도 그대로 테스트할 수 있게 해주는 얇은 래퍼입니다. 실제 확장
프로그램에서는 필요 없는 파일이고, `chrome-mock.js`가 `chrome.runtime.getURL('popup.html')` 요청을
이 래퍼로 대신 연결해줘서 `content.js` 코드는 손대지 않고도 그대로 동작합니다.

## 알아두면 좋은 차이점

- 여기서 저장되는 설정은 **이 미리보기 페이지 전용**입니다(브라우저의 `localStorage`에 저장).
  실제 크롬 확장 프로그램의 `chrome.storage.local`과는 완전히 별개라서, 여기서 바꾼 값이
  실제 익스텐션에 영향을 주지도, 그 반대도 아닙니다.
- 상단 "🗑 저장된 설정 초기화" 버튼으로 미리보기 전용 저장값만 지울 수 있습니다 (온보딩 화면부터
  다시 보고 싶을 때 유용합니다)
- 유튜브의 실제 DOM 구조가 아니라 **최소한으로 흉내 낸 것**이라, 실제 방송에서만 나타나는 케이스
  (슈퍼챗, 멤버십, 이모지 렌더링 등)는 여기서 재현되지 않습니다. 최종 확인은 항상 실제 유튜브
  라이브 방송에서 한 번 더 해주세요.
