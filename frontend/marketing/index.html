Why FILTERME

채팅창, 이제 신경 쓰지 마세요

방송에 집중하고 싶은데 도배와 악플이 눈에 계속 들어온다면, FILTERME가 대신 걸러드립니다.

⚡

실시간 처리

채팅이 올라오는 즉시 AI가 분석해서, 화면에 뜨기 전 걸러낼 채팅을 판단해요.

🔒

채팅 기록 저장 안 함

분석은 실시간으로만 이뤄지고, 채팅 내용은 어디에도 저장되지 않아요. 필터 기준만 브라우저에 남아요.

🎵

내 맘대로 설정

항목별로 켜고 끄고, 걸러진 채팅은 블러 처리할지 완전히 숨길지도 직접 골라요.

필터 기준

4가지 기준으로 채팅을 분류해요

켠 항목에 대해서만 필터가 동작해요. 예를 들어 욕설만 켜면 욕설로 판정된 채팅만 숨겨져요.

SPAM

도배

  • 같은 내용 반복
  • 과도한 "ㅋㅋㅋㅋ", "ㅎㅎㅎㅎ" 반복
  • 이모지 반복
  • 짧은 시간 내 유사 채팅 반복
PROFANITY

욕설

  • 욕설 · 비속어
  • 수위가 높은 표현
AGGRESSION

비방 / 공격

  • 특정 사람을 향한 비난
  • 시비성 · 모욕적인 표현
  • 공격적인 채팅
ADVERTISING

광고 / 홍보

  • 반복적인 홍보 문구
  • 외부 사이트 · 서비스 홍보
  • 방송과 무관한 홍보성 채팅
How it works

작동 방식은 간단해요

최종적으로 무엇을 숨길지는 항상 당신의 설정이 결정해요.

1

AI가 채팅을 분석해요

채팅마다 도배 · 욕설 · 비방 · 광고 항목별로 0~100 점수를 매겨요.

spam82
profanity15
aggression63
advertising4
2

내 설정과 비교해요

켠 항목의 점수가 임계값 이상이면 필터 대상으로 판정돼요. 판정은 항상 내 브라우저에서 이뤄져요.

3

화면에서 걸러내요

기준을 넘은 채팅은 블러 처리하거나 완전히 숨겨요. 블러는 클릭하면 다시 볼 수 있어요.
